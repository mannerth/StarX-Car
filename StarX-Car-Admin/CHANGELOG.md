# Changelog

## 2026-09-01

- 修复订单详情错误读取顶层 `totalFare` 导致已结算总金额显示为 `¥NaN`；改为读取后端 `fare.totalFare`，并为金额空值和非法值提供占位显示。
- 投诉处理弹窗新增明确的“用户投诉原因”区域；投诉类型、用户状态、司机账号状态、订单费用项和订单时间线枚举统一显示为中文。
- 明确计费规则用途标签：新订单实际使用的规则显示为“新订单默认”，其他活动规则显示为“已启用（非默认）”；规则页补充用途说明，并允许将已启用的非默认规则直接切换为新订单默认。

## 2026-08-31

- 引入 Element Plus 与图标库，新增统一 `AdminLayout`：集中维护导航、管理员账号菜单和退出登录，移除订单、预约、投诉、用户、司机、计费和个人中心页面中重复的侧栏框架。
- 重构全局后台视觉与响应式布局，统一运营工作台的顶部栏、菜单、页面标题、表格、状态标签、表单、弹窗和信息面板；路由改为按需加载，降低非当前页面的初始加载开销。

- 新增投诉工单运营页，支持状态筛选、关联订单跳转、查看投诉内容以及道歉、驳回、部分退款和全额退款处理。
- 计费规则维护页新增到达取消费，订单各运营视图支持中途结束状态。

- 新增订单监控、预约运营和订单详情页面：支持订单筛选、运营摘要、预约倒计时、费用明细、状态事件、司机最后位置文本和追加式运营备注。
- 新增受控运营操作：管理员可填写原因取消 `SCHEDULED`/`PENDING` 订单，或提前派发 `SCHEDULED` 预约订单；操作后立即刷新服务端状态。
- 新增管理端订单 API 类型与 Axios 封装，补齐全部页面导航、桌面与窄屏布局；列表、预约页和详情页分别采用 30 秒、15 秒和 10 秒 HTTP 轮询，页面隐藏时不发起自动刷新。

## 2026-08-08

- 新增司机审核页面：支持审核状态筛选、跨账号与证件资料搜索、分页查看身份/驾驶证/当前车辆信息，以及对待审核司机执行通过或驳回操作。
- 新增计费方式管理页面：支持规则状态筛选、完整分段明细查看、新建和编辑草稿、激活、切换默认规则及归档；内置里程、行程时间、等待时间三类可编辑分段。
- 新增司机审核与计费规则的 TypeScript 类型和 API 封装，并将两项运营能力接入全部管理端页面导航。
- 调整桌面和 Android 常见窄屏下的导航、筛选器、数据表和计费编辑弹窗布局；完成 TypeScript 检查、Vite 生产构建与 Playwright 桌面/移动端截图验证。
